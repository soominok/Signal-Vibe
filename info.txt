[1] 한 줄 정의 (One-liner)
---------------------------------------------------------------------
"지금 어디에 돈이 몰리는지 한눈에 보여주는 주식 투자 정보 대시보드"

[2] 목적 (Why)
---------------------------------------------------------------------
- 1차 목표: 내가(창업자) 매수/매도 타이밍 판단에 실제로 활용해 수익을 낸다.
- 2차 목표: 소액 구독 결제(월 4,900원 / 19,900원) 기반 수익화.
- 핵심 가치: 흩어진 시황·뉴스·섹터·종목 정보를 "돈의 흐름" 관점으로
  한 화면에 묶어서, 판단에 걸리는 시간을 줄인다.

[3] 타겟 사용자 (Who)
---------------------------------------------------------------------
- 개인 투자자 (정보 과부하에 지친 직장인 투자자)
- 확장: 소규모 투자 스터디 → 기업 리서치팀 (B2B)

[4] 제공 정보 (What)
---------------------------------------------------------------------
- 시황 분석 (오늘/이번 주 시장 요약)
- 미시/거시 경제 뉴스 분석 및 종목·섹터 연결고리
- 일/주/월/년 단위 주요 섹터 발굴 + 상승/하락 원인 설명
- 관련 산업 및 기업 상세 페이지 (재무, 뉴스, 차트, 연관 종목)

[5] 기술 스택 (How) — 변경 가능, 결정되면 여기서 고정
---------------------------------------------------------------------
- 프레임워크 : Next.js (App Router, TypeScript)  ← 정보 페이지 SEO에 유리
- 스타일     : Tailwind CSS + shadcn/ui
- DB / 인증  : Supabase (PostgreSQL + Auth)
- 결제       : 포트원(PortOne) 또는 토스페이먼츠 (국내 소액 정기결제)
- 데이터 분석/요약: LLM API (뉴스 요약·섹터 원인 설명)
- 배포       : Vercel
- 데이터 소스(검토 대상):
    * 국내 시세/기업: 한국투자증권 KIS Developers API (무료 등급 존재)
    * 뉴스: 뉴스 API 또는 RSS (저작권/이용약관 확인 필수)
    * 거시 지표: 한국은행 ECOS, FRED 등 공공 API
  ※ 네이버/다음 금융 크롤링은 약관 위반 소지 → 기본 배제, 공식 API 우선.

[6] 절대 제약 (Hard Constraints)
---------------------------------------------------------------------
- [법규] 한국에서 "유료로 매매 시점을 추천"하는 서비스는 자본시장법상
  '유사투자자문업 신고' 대상이 될 수 있다. 유료 결제 기능을 켜기 전에
  반드시 신고/면책 구조를 갖춘다. (창업자가 별도 확인 — 본 프로젝트는
  법률 자문이 아님)
- [면책] 모든 분석 화면 하단에 "본 정보는 투자 참고용이며, 투자 책임은
  본인에게 있습니다" 고지를 항상 노출한다.
- [개인화 금지] 특정 사용자에게 "지금 OO 사세요" 식의 1:1 맞춤 매매
  지시는 하지 않는다. (이는 정식 투자자문업 영역)
- [비용] 실시간 데이터·LLM API는 비용 발생. 호출은 캐싱하고,
  무료 사용자에겐 지연/제한된 데이터만 제공한다.
- [정확성] AI가 생성한 분석은 "AI 생성" 라벨을 붙이고, 출처 링크를 단다.

[7] 수익화 구조
---------------------------------------------------------------------
- 무료     : 주간 트렌드 요약 (지연 데이터)
- 프리미엄 : 월 4,900원 — 심층 분석 + 관심종목 알림
- 비즈니스 : 월 19,900원 — 팀 단위 리포트
- 추가     : 제휴 금융상품 커미션 (추후)

[8] 용어집 (Glossary) — 코드/UI 네이밍 통일용
---------------------------------------------------------------------
- Sector       : 산업 섹터 (예: 반도체, 2차전지)
- HotSector    : 자금이 집중 유입된 상위 섹터
- Ticker       : 종목 (코드 + 이름)
- MoneyFlow    : "돈의 흐름" 지표 (거래대금/수급 기반)
- Insight      : LLM이 생성한 분석 텍스트 (항상 출처 동반)
- Watchlist    : 사용자 관심종목

[9] 성공 지표 (단계별)
---------------------------------------------------------------------
- 0단계: 창업자 본인이 매일 1회 이상 접속해 판단에 사용
- 1단계: 가입 후 7일 재방문율(WAU/가입자) 30%+
- 2단계: 무료→프리미엄 전환율 3%+
